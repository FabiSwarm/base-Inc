# Shopify Server Actions

Hier kommt später `cart.ts` mit `"use server"` hin: ausführbare Aktionen zum
Hinzufügen, Ändern und Entfernen von Warenkorbpositionen.

Die Aktionen prüfen Eingaben, verwalten die Warenkorb-ID per Cookie und rufen
die Funktionen aus `lib/shopify/cart.ts` auf. API-Zugangsdaten bleiben auf dem Server.
Aktuell ist noch keine Aktion implementiert.
