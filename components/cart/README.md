# Warenkorb-Bauteile

Hier kommen später Warenkorbpositionen, Mengensteuerung, Zwischensumme und
Checkout-Button hin. Geplant: `cart-line.tsx` und `cart-summary.tsx`.

Die vorhandene Schublade `components/layout/cart-sheet.tsx` bleibt die äußere
Darstellung. Diese neuen Bauteile werden dort eingebunden und lösen Änderungen
über die Server Actions in `app/_actions/shopify/` aus.
