# Daten für die Oberfläche aufbereiten

Hier kommen Funktionen hin, die Shopify-Antworten in die Datenform der
Produkt- und Warenkorb-Komponenten übersetzen. Geplant: `product.ts` und `cart.ts`.

Hier werden beispielsweise GraphQL-Verbindungen in Listen umgewandelt und
fehlende Bilder behandelt. Preise, Währungen und Verfügbarkeit kommen aus Shopify.
Diese Funktionen führen selbst keine API-Anfragen aus.
