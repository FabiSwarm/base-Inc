# Lesende Shopify-Abfragen

Hier kommen die GraphQL-Abfragen für Produktlisten, einzelne Produkte mit
Varianten sowie den aktuellen Warenkorb hin. Geplant: `products.ts` und `cart.ts`.

Die Abfragen beschreiben die benötigten Felder. HTTP-Zugriff und Authentifizierung
übernimmt später der gemeinsame Client eine Ebene darüber.
