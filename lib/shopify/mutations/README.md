# Schreibende Warenkorb-Operationen

Hier kommt `cart.ts` mit den GraphQL-Mutationen zum Erstellen des Warenkorbs sowie
zum Hinzufügen, Ändern und Entfernen von Positionen hin.

Jede Mutation soll die aktualisierten Warenkorbdaten und Shopify-`userErrors`
abfragen. Aufgerufen wird sie über die serverseitigen Warenkorbfunktionen.
