# Wiederverwendbare GraphQL-Felder

Hier kommen gemeinsam verwendete Felder für Produkte, Varianten, Geldbeträge
und Warenkörbe hin. Geplant: `product.ts`, `cart.ts` und `money.ts`.

So fragen Produkt- und Warenkorboperationen dieselben Daten in konsistenter Form ab.
Die Fragmente werden zusammen mit den Abfragen und Mutationen implementiert.
