# Shopify-Datentypen

Hier kommen TypeScript-Typen für die tatsächlich abgefragten GraphQL-Daten,
Variablen und Fehler hin. Geplant: `product.ts`, `cart.ts` und `graphql.ts`.

Die Typen sollen zum ausgewählten API-Schema und zu den konkreten Operationen
passen. Die lokalen UI-Typen in `types/product.ts` bleiben davon getrennt.
